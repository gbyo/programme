Programme

Soccer scorekeeping for iPad.

Programme is a scorebook for recording soccer matches live from the sideline. Track the match as it happens, review the record, and export game and season statistics.

Shot locations

Record shots on the pitch.

Add a shot location with touch or Apple Pencil. Programme uses different marker shapes for goals, shots on target, shots off target, blocks, and woodwork.

  • Goal
  • On target
  • Off target
  • Blocked
  • Woodwork

Attacking left to right. The pitch is drawn to real proportions, and the map stays readable with Differentiate Without Colour turned on because shape carries the outcome.

Match review

Review the match before finalizing it.

Programme collects unresolved players, lineup problems, incomplete periods, and other items that still need attention in one place.

Items that need review do not interrupt live scoring.

Needs review 2 open

  • Unidentified player Shot · 41:08 Review
  • Lineup 10 of 11 players Review

A shot recorded without a jersey number counts toward team totals immediately and waits here for a player. Assigning one revises the original event rather than adding a second.

Recovery

Match recovery

Programme keeps a recovery journal while a match is being scored so recent changes can be recovered separately from the normal saved match data.

Scoring needs no account, no network and no server.
